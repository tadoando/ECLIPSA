# ADR-0005 · La mesa usa un único tema oscuro

**Estado:** aceptada · v0.1

## Decisión
La pantalla de juego tiene una sola identidad visual nocturna (índigo y oro), con variaciones de ambiente por fase. No sigue el tema claro u oscuro del sistema.

## Consecuencias
Coherencia con el tema del eclipse y un control total del contraste de las cartas. Los menús y ajustes pueden adoptar el tema del sistema más adelante.
